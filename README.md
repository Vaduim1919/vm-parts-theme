# vm-parts-theme

Тема **VM Parts** для OpenCart 3 — інтернет-магазин автозапчастин V&M Auto Parts (vmautoparts.com.ua).

## Встановлення (перший раз)

1. Завантажте `releases/vm_parts-<остання версія>.ocmod.zip`.
2. В адмінці OpenCart: **Розширення → Встановлення розширень** → завантажте архів.
3. **Розширення → Розширення → Модулі** → «VM Parts — тема сайту» → зелений «+» → олівець.
4. Заповніть контакти та натисніть **«Увімкнути тему VM Parts»**.

## Оновлення

В налаштуваннях теми, блок **«Оновлення»** → **«Перевірити оновлення»** → **«Оновити до версії…»**.
Тема читає файл [`latest.json`](latest.json) з цього репозиторію, завантажує архів, перевіряє контрольну суму (sha256)
і замінює лише файли теми. Перед оновленням робиться резервна копія, кнопка **«Відкотити»** повертає попередню версію.

## Для розробки

- `src/upload/` — файли теми й модуля (структура ocmod.zip).
- `tools/release.sh 1.1.1 "Що нового"` — збирає `releases/vm_parts-1.1.1.ocmod.zip` і оновлює `latest.json`.
- `tools/gen_lists.py`, `tools/gen_product.py` — генерують шаблони списків товарів і сторінки товару з шаблонів default
  (в OpenCart 3.0.4 Twig не підтримує `include`, тому картка товару вбудована в кожен шаблон).
